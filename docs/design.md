# Npp Markdown Lite

基于 Notepad++ 官方 master `67eca422e60a169801a9aaeb19e285b7f27cfd13`（8.9.9 开发树），保留 Win32 / Scintilla 编辑区、标签栏、查找替换、列选择、多选区、文件编码、分屏与原生插件接口。不是独立重写，也不采用 WebView / Electron。

## 精简边界

- 使用编译期精简菜单和工具栏，不依赖用户隐藏配置。
- 去掉宏录制/播放、外部运行与散列工具命令；不携带更新器、预装插件、语言包或补全数据库。
- 保留基础编辑、正则查找替换、常用语言高亮、首选项、快捷键设置、手动导入插件与插件文件夹。
- 插件仍是第三方原生代码，必须自行核对可信来源和 x64 架构。保留 ABI 不表示所有第三方插件均已测试；依赖官方窗口类名或完整菜单位置的插件可能需要适配。

## Markdown

- `.md/.markdown/.mdown/.mkd/.mdwn` 自动使用内置 Lexilla Markdown 词法器，不新增或重排插件语言枚举。
- 原文始终可见可编辑：标题字号层级、强调、链接、引用、行内代码、围栏代码、分隔线和 front matter 的原生样式；浅色和深色配色。
- 开启 Markdown 时采用可读字号、额外行距、字符级软换行；切回其他文件恢复原先设置。表格保持等宽原文；提供显式对齐命令，不在打开/保存时重写内容。
- 常用命令：粗体、斜体、行内代码、链接、代码围栏、任务勾选、表格对齐、前后标题跳转、增强样式开关。
- Enter 延续无序列表、有序列表、任务列表与引用；空项目退出；代码块、多选区、宏回放和只读文档不触发。
- 不隐藏语法，不执行 HTML/JavaScript，不读取远程图片；不是 HTML 预览器，也不宣称完整 CommonMark 渲染。

## 发行与隔离

- Windows x64 单个 EXE，静态 CRT，运行时只依赖 Windows 系统组件；默认 XML 作为资源嵌入。
- 独立 `%APPDATA%\NppMarkdownLite` 配置目录、窗口类与单实例互斥量，不覆盖官方 Notepad++ 设置或安装。
- GitHub Actions 生成发布物，未压壳 EXE 必须小于 10,000,000 字节。体积超标或测试失败则不发布。
- 保留 GPL-3.0-or-later 许可证、原作者版权、上游源码和提交血缘；明确非官方发行。

## 验证

纯 C++ 测试覆盖列表/任务/引用解析、围栏边界、标题识别、表格分割和幂等对齐。Windows 集成测试通过真实窗口和 Scintilla 消息验证首启、样式、源码无损、Markdown 与其他文件切换、编辑命令、菜单/工具栏裁剪及测试插件加载。源码与 release 的 SHA、体积和 SHA256 写入发布回执。
