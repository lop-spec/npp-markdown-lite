# Npp Lite

原生编辑器与 Markdown 插件分工：编辑区保持 Notepad++ 的字符编辑、紧凑行距、列模式、搜索替换和插件消息协议；Markdown 的渲染交给完整安装的官方 Markdown Panel 0.9.3 x64。不内置自写 Markdown 解析器或富文本编辑逻辑；源码高亮使用原生UDL，默认宋体、统一11磅和原生行高。

## 精简

80个新增退役主命令列在 `PowerEditor/src/Lite/RetiredCommands.h`。`NppCommands.cpp` 中对应完整处理分支通过编译条件排除，主分发入口拒绝退役ID；`Parameters.cpp` 不再为其注册快捷键。历史宏、Run和哈希工具继续不编译。保留ABI必要的共用设施，不宣称所有上游辅助实现都被物理删除。

主工具栏8个实际按钮、2个分隔符；插件可以继续按原生接口追加自己的按钮。全部保存、剪切、复制、粘贴移出工具栏而不是删掉基础能力。

自写Markdown的4个代码文件、12个命令ID、编辑通知钩子、语言样式钩子、缓冲区状态、保存扩展名逻辑和独立测试均删除；5个受影响原生源码文件完整恢复到官方基线。单文件配置和精简菜单放入与Markdown无关的Lite目录。

## 首选项和语言

首选项保留14页；工具栏装饰、非打印字符细项、文件关联、语言菜单、高亮、打印、多实例、分隔符、云与链接、搜索引擎10页不再创建。9页模板不编入EXE；文件关联模板因上游共用资源保留，但不再注册该设置页。98个可操作控件的清单由真实资源模板生成，不计标签；保持原生历史页索引到新列表的映射，已退役页的内部链接安全拒绝。

`deploy/prepare-ui-assets.py`在构建前生成官方中文、宋体默认样式、原生Markdown深浅UDL和样式中文显示名。样式列表存原始键为ItemData，保存和行为判断不使用译名；语法配色仍为上游配置格式。UDL配置来自Edditoria/markdown-plus-plus，固定来源提交`bad918ee8fbf322f723bf5dd4162a462837720f2`，MIT许可随包提供。复杂嵌套语法仍受原生UDL能力限制，不声称替代完整Markdown渲染。

## 插件

只安装官方插件，不改其DLL、CSS、JS或网络策略。宿主仅对Markdown Panel菜单及设置窗口的标签提供中文显示，跳过文本框和下拉数据；调用结束立即卸载线程钩子，其他插件不受影响。固定下载与SHA256在 `deploy/plugin-lock.json`；保留官方完整lib、帮助、样式和License。需要 .NET Framework 4.7.2+、WebView2 Runtime，不静默安装系统运行时，不误称主EXE包含这些运行时。

便携包默认自动打开支持扩展名的面板，禁用额外插件工具栏/状态栏。源文仍在原生编辑区编辑。通过实际可访问WebView2文档中的标题及编辑后变化验收渲染；不把DLL加载成功当作可用。

## 发布与转移

云端CI产生EXE及含插件便携包。EXE未压壳且严格小于10,000,000字节；附校验和、构建SHA、完整便携包SHA、80项命令清单和测试结果。

对端部署到独立NppLite目录，不停止或覆盖用户正在运行的编辑器；覆盖已有同用途文件之前备份。传输后校验包和EXE，验证插件、运行时和真实打开/渲染，不以scp退出0代替安装验收。
