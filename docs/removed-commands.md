## 自写 Markdown 删除

删除 MarkdownCore、MarkdownLexer、MarkdownView、MenuIds 四份自写代码及12个命令，删除专用测试；恢复Buffer、ScintillaEditView、NppNotification、NppIO等官方原生逻辑。不存在标题放大、额外全局行高、智能续列表、任务切换、表格对齐或内置Markdown菜单。官方Markdown Panel以独立插件安装。

## 工具栏

12键降至8键，移走「全部保存、剪切、复制、粘贴」4个按钮；这些基础命令与快捷键仍可用。保留：新建、打开、保存、撤销、重做、查找、替换、自动换行。插件按钮允许正常追加。
